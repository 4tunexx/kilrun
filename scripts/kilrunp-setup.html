KilrunP setup

Prepare your website, multiplayer server and database. This private setup page is available only through your host's local connection or an SSH tunnel.

Use a new, empty MongoDB database. Installation will install dependencies, update its schema, load initial content and build the application. This does not start your hosting services or configure HTTPS.

Configure your host's TLS proxy to forward WebSocket traffic to the game server. Use a dedicated database with replica-set support. URL-encode special characters in the connection string. Configure the Clerk webhook at your website origin followed by /api/webhooks/clerk.
